# Hi, I'm Darling 👋

I'm a final-year Software Engineering student at Miva Open University (graduating 2027). I build software that people can understand and trust: AI that shows its sources, interfaces that adapt to the reader, and navigation that works for people who cannot take the stairs.

**What I care about:** human-centred AI, accessible design, interaction technology, and honest evaluation. Most of my projects ship with a small study kit so the results can be measured instead of assumed.

## How I work
- **Evidence over claims.** Where a project makes a claim (for example "citations increase trust" or "this font helps"), the repo includes a protocol to test it. I add results to the READMEs only after I have run the studies.
- **Tested logic.** Core logic lives in small, pure modules with unit tests and CI.
- **Accessible by default.** Keyboard access, readable type, reduced motion and plain-language messages.
